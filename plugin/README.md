# token-efficient-work

The Claude plugin directory entry of [token-efficient-work](https://github.com/vannt-dev/token-efficient-work):
the skill only. Five rules that stop coding agents from burning tokens on redundant reads, re-checks
and long explanations. No hooks, no scripts, no network calls.

This folder is a copy kept in step with the repository root by a test; the skill's source is
`skills/token-efficient-work/SKILL.md` at the root, and the README there covers the other ways to
install it and the optional hooks.
