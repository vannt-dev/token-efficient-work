A rule for Claude Code · Codex · Copilot CLI · Gemini CLI · Cursor · Aider

Your agent already knows the file didn't change. Stop making it check.

token-efficient-work is a portable skill + config hook that stops coding agents from re-reading files they just edited, opening whole files for two-line changes, running unrequested "just to be safe" checks, and over-explaining what the diff already shows.

  3. Get-Content -Raw utils.py
  4. apply edit
  5. rg "calc_total|compute_total" — again

  1. read SKILL.md once
  2. rg "calc_total|compute_total"
  3. apply edit

02The fix — five rules

Every read, re-check, and sentence of output should add information the agent doesn't already have. If it doesn't, skip it.

  1. 01

    Locate before you read

    Search first, then read only the matching range — not the whole file, on the chance something in it is relevant.

  2. 02

    A successful edit doesn't need a confirmation read

    If the tool reported success, the change applied. Re-reading to "make sure" spends a full file for zero new information.

  3. 03

    Verify proportionally to what's at stake

    Name the specific risk a check rules out before adding it. "Can't hurt to check" is not a risk.

  4. 04

    Reuse what you already established

    Read a file or ran a command already this session? Use that result instead of re-fetching it "to be current."

  5. 05

    Match output length to the question

    A yes/no question gets a sentence. Don't restate a diff the user can already see.
