## Token-efficient work (global rule, all projects)
Before reading, re-checking, or explaining, apply these (full detail + rationale: `~/.agents/skills/token-efficient-work/SKILL.md`):
1. Search/locate before reading; read only the needed range, not whole files.
2. Don't re-read a file just to confirm an edit that already reported success.
3. Verify proportionally to risk — name the specific risk before adding a check.
4. Reuse facts already established this session instead of re-fetching them.
5. Match output length to the question; don't restate diffs/tool output in prose.
